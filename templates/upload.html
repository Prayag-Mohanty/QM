Connect to GitHub (one time on this device)

Uploads are saved to the {{ site.github_repo }} repository, and the site republishes itself automatically. Paste a GitHub access token that can write to that repository.

How to get a token (2 minutes)
  1. Open GitHub → New fine-grained token.
  2. Name it “QM Prayag upload” and pick the longest expiration.
  3. Repository access → Only select repositories → {{ site.github_repo.split('/')[-1] }}.
  4. Permissions → Repository permissions: Contents → Read and write. Optionally Actions → Read-only to see publishing progress here.
  5. Click Generate token, copy it and paste it below.

The token is stored only in this browser. Use Disconnect on shared computers.
